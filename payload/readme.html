Brave Portable 使用说明

本文件夹是一个真正便携的 Brave 浏览器包。所有用户数据保存在文件夹内的 data 目录，宿主机 C 盘不留残留，复制整个文件夹即可迁移。

四条规则

  1. 解压后先运行 setup.bat（已完成则会打开本页）。
  2. 不要点击 Brave 内部的“设为默认浏览器”。
  3. 数据始终在 data 目录，复制整个文件夹即可带走。
  4. 移动文件夹或换机器后，重跑一次 setup.bat（换机器还需重新设一次默认浏览器）。

设置默认浏览器（手动一次）

由于 Windows 的安全机制，程序无法自动设置默认浏览器，需要你手动确认一次：

  1. 点击下方按钮打开系统“默认应用”设置。
  2. 在列表中找到 “Brave Portable”，点击它。
  3. 将“http”和“https”都设为 Brave Portable。

注意：务必从列表中选择名为 “Brave Portable” 的条目。 不要用“选择其他应用 → 按路径指向 exe”的方式，那样系统会另建关联，导致外部链接仍走错路径。

启动方式

  • 桌面快捷方式（推荐）：无命令行窗口，每次启动自动检查并修正注册路径。
  • 外部链接（他处点击网址）：经系统协议调用本启动器，数据落入 data。
  • 直接双击 brave-portable.exe：也可，但不触发路径自检。

任务栏固定

如需从任务栏启动，请右键 brave-portable.exe →「固定到任务栏」，从该图标启动会经过启动器，数据正确落入 data。

切勿右键运行中的 Brave 图标固定——那是 app\brave.exe，从它启动会绕过启动器，数据落 C 盘并在退出时被 cleanup 清理，导致数据丢失。

数据与迁移

所有数据（书签、历史、Cookie、密码、扩展等）都在本文件夹的 data 目录。

  • 同机迁移：移动整个文件夹后，重跑 setup.bat 即可。
  • 换机器：复制整个文件夹到新机 → 运行 setup.bat → 在新机系统设置里重新设一次默认浏览器。

取消注册

若不再使用，运行 unregister.bat 可删除全部注册表键（可重复运行）。

取消注册前，请先在系统设置里把默认浏览器改回其他程序，否则外部链接将无法打开。

安全提示

明文存储：为支持跨机器使用，Cookie、保存的密码、自动填充、会话令牌等均以可解密方式存储在 data 目录。 请像保管密码一样保管本文件夹——建议置于加密卷（如 BitLocker），切勿放在共享盘或同步盘。
混装风险：本包启用 cleanup: true，退出时会清理 %APPDATA%\BraveSoftware 与 %LOCALAPPDATA%\BraveSoftware。 若本机同时安装了普通版 Brave，其用户数据可能被一并清理。请勿混装，或知悉此风险后再用。
杀毒软件：修改 http/https 关联的行为与“浏览器劫持”相似，可能被杀毒/EDR 拦截或回滚。若被拦截，需在杀毒软件中放行本脚本。

故障排查

  • 外部链接打不开 → 检查系统设置里默认浏览器是否为“Brave Portable”。
  • 迁移后打不开 → 重跑 setup.bat。
  • 列表里看不到“Brave Portable” → 重跑 setup.bat（可能 ApplicationDescription 缺失）。
